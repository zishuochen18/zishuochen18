# 港澳商务周报系统

一键生成包含 6 个模块的港澳商务周报 HTML 页面。

---

## 一、快速开始

### 运行命令
```bash
cd "周报内容"
python generate_weekly_report.py
```

输出：`周报内容/output/港澳商务周报.html`（用浏览器打开查看）

### 运行前的准备

必备命令：
```bash
python check_data.py        # 检查所需的数据底表是否齐全
python generate_weekly_report.py  # 一键生成周报
```

## 六、注意事项

### 模块 5 - 线下商超

- **VENUE_DAYS_MAP 维护**：每月有新场次时，在 `process_shangchao.py` 顶部配置出摊天数：
  ```python
  VENUE_DAYS_MAP = {
      "啟田商場3場": 4,
      "樂富商場市集": 4,
  }
  ```
- **CPS/CPT 公式**：CPS = 滚动GMV × 0.35；CPT = 滚动消耗 - CPS
- **本月场次**：例子数 > 0 才算有效场次（"5月分场次明细" 用此口径）
- **分月趋势的本月行**：所有非展会线下HK供应商总和（包含例子=0但有滚动消耗的场次）

### 模块 6 - 转介绍打卡

- **统计周期**：本期=当月1日到昨天，上期=上月1日到上月对应日期
  - 如今天 6.3，本期 6.1-6.2，上期 5.1-5.2
- **手推/非手推筛选**：先筛 `推荐人业绩归属（首消）= 班主任`，再按 `末次渠道名称` 区分
  - 手推：末次渠道名称 = "手推链接"
  - 非手推：末次渠道名称 ≠ "手推链接"
- **打卡链路例子数**：从销售明细取 3 个特定渠道：
  - 【海外益智】平台小程序连报（海报）
  - 【海外】抽奖活动
  - 【海外益智】平台小程序联报（FB/WhatsApp）
- **带量明细文件命名**：必须按 `{月}.{日}-{月}.{日}` 格式开头，按月份排序识别本期/上期

### 模块 4 - 书展

- **本月书展供应商列表**：每月在 `process_book_fair.py` 顶部更新：
  ```python
  BOOK_FAIR_SUPPLIERS = ["26年5月第十二屆兒童書展", "26年5月課外活動展"]
  ```

### 模块 2 - KOL 转化

- 钟嘉欣多个供应商（图片+视频1+视频2）汇总，公式自动嵌套
- 每月数据更新后，公式会自动重新计算

### 通用

- 运行前关闭已打开的 Excel 输出文件，否则会 `PermissionError`
- 路径含中文+空格，命令行加引号：`cd "周报内容"`
- 第一次运行需安装依赖：`pip install pandas openpyxl playwright`

## 九、常见问题

### Q1: 运行报错 "PermissionError: 文件被占用"
**A:** 关闭已打开的 Excel 文件再运行。

### Q2: 某个模块数据为 0 或不对
**A:** 
1. 先运行 `python check_data.py` 看是否所有底表都齐全
2. 再单独运行该模块的 `process_xxx.py` 看具体输出
3. 检查底表的列结构是否变化（特别是 BI 报表更新后）

### Q3: 提示"未找到对应月份的流速 sheet"
**A:** 在 `后端转介绍流速.xlsx` 中新增对应月份的 sheet，命名格式 `26年X月后端转介绍流速`。

### Q4: 商超模块"发现 X 个新增场次"
**A:** 在 `process_shangchao.py` 顶部 `VENUE_DAYS_MAP` 中配置该场次的出摊天数。

### Q5: 周报 HTML 怎么发给同事
**A:** 直接发 HTML 文件，对方用浏览器打开即可。如需 PDF，浏览器 Ctrl+P 另存为 PDF。
